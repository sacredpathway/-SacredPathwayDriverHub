Phase 5 - Technical SEO checks and exact fixes

  • Page speed: the generated static pages have no framework, no external JavaScript, and only lightweight CSS. Keep images compressed and lazy-load future screenshots.
  • Mobile usability: generated CSS uses responsive grids, stable card dimensions, and mobile-friendly tap targets. Validate in Search Console Mobile Usability after deployment.
  • Structured data: run every deployed template through Google Rich Results Test. Fix any warnings around aggregateRating if ratings change or become unavailable.
  • Indexability: submit /sitemap.xml in Google Search Console and use URL Inspection for the two app landing pages first.
  • Core Web Vitals: avoid Squarespace animation effects, large background videos, and heavy third-party embeds on the app landing pages. Use static image assets and defer non-critical scripts.
  • Sitemap coverage: remove malformed URLs from the live sitemap or 301 redirect them to the correct privacy/support pages.
  • Crawl errors: monitor GSC Pages report weekly for "Duplicate without user-selected canonical", "Crawled - currently not indexed", and "Not found (404)".
  • Internal links: add header/footer links to Bill Tracker, Driver Hub, Resources, and at least three high-intent keyword pages from the home page.
